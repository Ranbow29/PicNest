【软件简介】
PicNest 是一款专为画师、原画设计师与创作者量身打造的高性能本地素材管理软件。
本版本由纯 Rust + Tauri v2 深度重构，摆脱了传统 Electron 的庞大体积与内存占用，
提供毫秒级百万级图片检索、全屏截图批注、置顶透明穿透贴图、视觉找图与离线查重。

------------------------------------------------------------------------
【核心亮点与新特性】
------------------------------------------------------------------------
1. 全屏截图批注与置顶穿透描图 (Alt+Q / Alt+Shift+P):
   - 一键冻结全屏截图，智能识别桌面窗口矩形，支持高清屏幕零卡顿截屏。
   - 内置矢量批注（矩形/椭圆/箭头/自由画笔/马赛克/序号标点/文字），支持二次选中、拖拽位移、四角缩放与双击改字，1:1 无损合成导出或直接入库 PicNest。
   - 一键将参考图「置顶贴图」，支持 120Hz 原生跨屏拖拽与相对 DPI 缩放（混合 DPI 主屏与数位屏不跳变）、Alt+滚轮调节透明度、水平镜像/灰度观察。
   - PureRef 级纯净鼠标穿透描图：开启穿透后永久锁定无焦点穿透，绝不打断 XP-Pen / Wacom + CSP 绘画压感笔触；按全局热键（默认 Alt+Shift+P，可在顶部设置自定义绑定数位屏侧键）或托盘菜单一键切换。

2. 极致轻量与零依赖便携：
   - 单文件便携运行，无需安装，不写注册表，即开即用。
   - 彻底告别臃肿后台，内置相邻图片预解码池与简报/灯箱流光模糊，看图切换丝滑跟手。

3. 毫秒级原生高性能引擎：
   - 纯 Rust 多核并发扫盘与 SQLite WAL 高性能事务引擎，万张大图瞬间呈现。
   - 动态微防抖与视口虚拟滚动，高频快速点击、切换目录毫无卡顿。

4. Pinterest 视觉找图（以图搜图）：
   - 基于视觉感知特征精准寻源，框选局部细节即可一键检索相似灵感。
   - 智能适配透明通道白底融合与缩略图缓存降级，告别黑边与加载失败。

5. 双核查重矩阵（精确查重 + AI 语义查重）：
   - 精确查重：大小分桶预筛 + 快速分块 Hash + 逐字节防碰撞验证，毫秒定位重复文件。
   - AI 查重：本地 8×8 dHash / 32×32 色块粗筛 + 多模态视觉模型精筛，精准揪出缩放、裁切、水印与重压画稿。
   - 支持标准 OpenAI 兼容多模态视觉接口，可自由配置 API 地址、Key 与视觉模型。

6. 贴心的画师交互设计：
   - MP4 动态视频自适应帧缩略图提取，直观识别动态素材。
   - 原生多级色板提取与无框沉浸式五星评分系统。
   - 外部拖入与内部整理“防手滑”安全锁：严格整行归类，杜绝间隙失误误入未分类。
   - 绝对安全删除底线：所有删除操作一律移至 Windows 原生回收站，随时可撤回，数据万无一失；移入/还原/彻底删除配有柔和交互提示音（可在设置关闭）。

------------------------------------------------------------------------
【快捷键指南】
------------------------------------------------------------------------
- Alt + Q            : 全局全屏截图与矢量批注（可在顶部设置自定义）
- Alt + Shift + P    : 全局开关置顶贴图鼠标穿透（可在顶部设置自定义）
- T / Alt + 滚轮     : 聚焦贴图时切换穿透 / 调节半透明度（贴图非穿透时 滚轮缩放）
- 方向键 / 滚轮       : 浏览与切换素材
- 空格键 (Space)      : 快速大图预览 / 退出预览
- F2                 : 选中图片或文件夹快速重命名
- Delete             : 将选中素材安全移入回收站
- Ctrl + A           : 全选当前视图素材
- Ctrl + 单击 / Shift : 多选素材进行批量移动、打标签或评分
- 拖拽拖入           : 直接将外部图片或文件夹拖入对应文件夹行归类

------------------------------------------------------------------------
【数据安全与隐私声明】
------------------------------------------------------------------------
- 本软件所有索引、缩略图、色板及元数据均 100% 存储于本地，不含任何未授权上传或遥测后门。
- AI 查重功能仅在用户主动配置并勾选授权后，将微缩略图发送至用户指定的私有 API 地址，原始画稿绝不离机。
