## 一、弹簧手势（图标动效的灵魂）

单个"手势"= 640ms 的完整动作，不是按压力度，而是归一化进度 `phase ∈ [0,1]`。

```
关键帧  t = [0, .10, .36, .64, .82, 1.0]
数值    v = [0, -.12, 1.0, -.20, .065, 0]
分段插值 easeInOutCubic；状态曲线 Cubic(.18, 1.28, .32, 1)
```

读法：先小幅反向蓄力（-0.12）→ 冲到主峰（1.0）→ 回弹过冲（-0.20）→ 微颤（0.065）→ 归零。
**q 弹感来自这组数值本身**，不是位移滤镜调出来的。

**三层错峰**（"纸片跟随"的层次感）：lead/follow/trail 三个部件分别延迟 0 / 55ms / 110ms，
各自跑同一条弹簧——视觉上像一叠纸被风掀动依次跟上。

**接入姿势**：位移不是给整个图标加滤镜，而是**画进几何**——每个部件按自己的相位改路径坐标。
案例：筛选漏斗的三根滑轨各横移 ±5u；布局图标的侧栏 reflow 成顶栏（宽 5.5+11.5p、高 16-10.5p），
另两格补位；四宫格按行上浮 d×1.3；文件夹后纸随 q 上抽 2.6u、前板随 p 下压开口 2.1u。
→ 教训：**动效要动语义部件**（滑块真的滑动、格子真的重排），整体位移只会显得像 bug。

## 二、环境晃动（ambient）— 密度学

静止约 2.6s 后"偶尔"重播一次。移植结论：

| 场景 | 密度 | 效果 |
|---|---|---|
| 顶栏 4 颗 | 各 3-6s 随机 | 界面"活着"，不吵（一次只动一颗） |
| 文件夹树 34 颗全开 18-40s | 每秒约 1 处轻晃 | 实测偏吵 → 收敛为**只有当前高亮文件夹** 6-14s |
| 随机自弹（无交互含义） | — | 已移除：晃动应该有语义（选中/触发），纯随机是噪声 |

**原则：环境动效是少数派的特权。** 一屏内同时动的元素永远 ≤1-2。

## 三、集体晃动总线（全局编排）

任何"界面状态跃迁"触发全体图标同步做一次手势：

```
collectiveShake()  →  iconShake.value++  →  watch 的所有 AnimIcon/FolderIcon/主题按钮 play()
```

主题按钮（☀/☾/◐）不是 SVG 层图标，但用同一套 `springAt` 驱动旋转+缩放（16° / 1.10 峰值），
在挂载、hover、mousedown、换主题、以及 `iconShake` 集体晃动时播放；与顶栏其他图标同拍。
`AnimIcon` 的悬停监听挂到最近的 `<button>`（不是 SVG 本身），因此鼠标掠过按钮留白/文字区域也会播放手势；布局分母选项、漏斗、布局、窗控图标都适用。

触发点：切视图 / 换文件夹 / 切资料库 / 关大图 / 漏斗与布局弹板开关 / 点外部关闭面板 / 详情展开与褪去。
对应 Wenku8 的哲学：**面板关闭或正文更新，全体动效进行一次**——状态跃迁的"盖章"。
注意防抖：连续跃迁合并（总线本身是计数器，天然合并）。

## 四、入场波（网格内容动效）

```
520ms 共享时钟 easeOutCubic
每项墨水窗口 0.35 进度；延迟 = clamp((i - focus + 8) / 24, 0, 0.65) × 520ms
位移 (-8, -6) 随进度衰减；过冲曲线 Cubic(.2, 1.06, .35, 1) 留给吸附类动作
```

触发：视图切换 / 排序 / 筛选 / 内容更新（防抖 120ms 合并）。
虚拟滚动的坑：**延迟用全局序号 gi，不是窗口局部序号**——滚动补挂载的格子（gi≥48）禁用动画，
否则每滚一屏都放一次波。页眉头块参与波次（--d: 0）= "全体"感。

## 五、概览滑尺（ZCode/Monaco 语义）

- 单条 canvas 固定窗口右缘，**详情浮岛打开时覆盖它**（z：滑尺 10 < 浮岛 12）——不随浮岛缩放移动
- 轨道切 48 槽：槽 dash 宽度 = 该段图片**平均宽度轮廓**（内容剪影），不是均匀线
- 视口邻近槽按 **cos² 衰减抬升**（宽/亮/粗三维增强，半径 4.2 槽）= "波随滚动行进"
- 视口位置 = 单条金色加粗指示 dash（12px 右对齐），替代"视口内全部涂金"的糊成一坨
- 原生滚动条隐藏（滑尺接管职能，否则双滑块残留）

## 六、Vue/工程踩坑（动效实现特有）

1. **setup 内 TDZ**：watch/computed getter 注册即求值，引用晚声明的 const 直接 ReferenceError 白屏。
   新代码块一律放全部依赖声明之后。
2. **ref 在普通对象里不解包**：`GLYPHS = { d: someRef }` 模板里拿到的是 ref 本身——
   存取值函数 `d: () => ref.value` 或直接映射成数值。
3. **模板作用域没有 window/innerWidth**：菜单定位 `Math.min(x, innerWidth)` → NaNpx → 元素钉在左上角。
   一律在 computed 里取。
4. **CSS 动画 vs transform 定位**：入场波不能打在用 transform 摆位的元素上（会覆盖定位），
   打其内层包裹（.thumb）。
5. **canvas 替换元素**：`position:fixed + top + bottom + height:auto` 会吃 intrinsic height
   （bottom 被无视，只剩 18px）——显式 `height: calc(100vh - 100px)`（随主面板 上/右 8px、下 22px 外缝；改 margin 要同步）。
6. **合成事件测不了 OS 层**（app-region 血泪的延伸）：但纯 DOM 逻辑（无 app-region）用
   dispatchEvent + 组件内部状态探针（`el.__vueParentComponent.setupState`）可以精确断言。
7. **python 脚本插代码进函数体**：用 `find('}')` 式锚点会切进内层函数——插桩后必须通读受影响函数。
8. ** reduced-motion**：所有波次/弹簧在 `prefers-reduced-motion: reduce` 下关闭，一行媒体查询。
