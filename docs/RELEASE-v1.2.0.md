> 本次大版本带来从零构建的 **原生多屏截图与可二次编辑矢量批注引擎**、**混合 DPI 自适应置顶参考贴图与 PureRef 级纯净鼠标穿透描图**、**灯箱相邻预解码池与流光模糊渲染优化**、**回收站交互音效**，以及 **浏览器采集扩展 v0.3.4 交互自愈升级**。

## ✨ v1.2.0 核心更新亮点

### 1. 原生多屏截图与可二次编辑矢量批注 (`Alt+Q`)
- **毫秒级多屏冻结截屏**：全局热键（默认 `Alt+Q`，可在顶栏设置自定义重绑）即时冻结全屏画面，基于 DWM 扩展边框实时吸附桌面窗口矩形，支持跨高/低 DPI 显示器无偏捕捉。
- **全能矢量批注工具链**：内置矩形、椭圆、实心箭头、自由画笔（二次贝塞尔平滑）、马赛克、序号标点（1、2、3…自动递增与撤销衔接）与可编辑文字工具，提供 3 档线宽/字号与 6 色高对比调色板（矩形/椭圆按住 `Shift` 等比，箭头按住 `Shift` 每 `15°` 吸附）。
- **批注二次操纵与无损合成**：已画出的矩形/椭圆/箭头/画笔/序号/文字均可随时点选（选中显示柔和选中框与四角缩放手柄）、拖拽移动位置、拉角调整尺寸、双击文字原位改字，或按 `Delete` 单删；1:1 物理像素合成导出 PNG / 复制带透明与位图双格式剪贴板 / 一键入库 PicNest。

### 2. 置顶参考贴图 & PureRef 级纯净鼠标穿透描图 (`Alt+Shift+P`)
- **轻量独立悬浮参考窗**：一键将截图悬浮置顶；保留精确半透明度（`WS_EX_LAYERED` + `LWA_ALPHA`）、水平镜像（`H`）、灰度观察（`G`）、`Alt+滚轮` 调透明度、滚轮缩放在内的高频画师工具。
- **混合 DPI 与跨屏 120Hz 原生跟随拖拽**：主屏与数位屏混合缩放比下拖动不跳变（`SWP_NOSIZE`），按屏幕比例相对缩放（默认居中或锚点缩放）。
- **PureRef 级永久纯净穿透 + 可自定义全局热键**：开启「鼠标穿透描图」后，贴图窗体永久锁定 `WS_EX_TRANSPARENT | WS_EX_NOACTIVATE`（完整保留所设半透明度），绝不与 XP-Pen / Wacom Wintab/Windows Ink 压感输入及 Clip Studio Paint 抢焦点或断触；可在顶栏设置将 **「贴图穿透开关」**（默认 `Alt+Shift+P`）自定义绑定至数位屏快捷键或左手键盘，并随时通过热键或托盘一键解锁。

### 3. 灯箱 / 简报观图性能与微交互体验升级
- **流光背景与预解码加速**：重写 `ambientBlur` 并优化 `Lightbox` / `BriefMode` / `CanvasStage` 渲染管线；新增相邻图片异步预解码缓冲池（`previewPreload`），切图更跟手。
- **柔和交互音效与视觉精修**：新增 Web Audio 合成的轻柔移入回收站 / 还原 / 彻底删除提示音（`soundFx`，支持在设置关闭）；进一步梳理主窗快捷键、WebView2 能力边界与界面响应流畅度。

### 4. 浏览器采集扩展 v0.3.4 采集体验升级
- 优化长按采集浮层与 Shadow DOM 事件隔离、新建分类文件夹交互反馈与重复实例自清理，配套全链路自动化 E2E 回归验证。
