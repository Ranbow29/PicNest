# PicNest v1.0.0 (Pure Rust & Tauri v2 Milestone Release)

> 🎨 **专为画师、原画设计师与视觉创作者打造的轻量级本地素材管理中心**  
> 告别臃肿的 Chromium/Node.js 运行时，全面拥抱纯 Rust 与 Tauri v2 原生引擎！

---

## 🌟 核心亮点与架构跃迁

### 1. 极致轻灵，零依赖便携
- **体积骤降 90%**：单文件仅约 18.5 MB，绿色免安装便携分发包（ZIP）压缩后**仅 5.93 MB**！
- **内存占用暴跌 85%**：彻底摆脱传统 Electron 庞大的后台资源开销，启动瞬间秒开，长久常驻轻巧安静。

### 2. 原生多核索引与 WAL 事务引擎
- **秒开万张原画**：基于多核并发扫描与 SQLite WAL 事务并发加速，深层子目录与数万张高分辨率插画也能毫秒级加载。
- **高频快速操作微防抖**：深度消除了频繁快速点击不同文件夹造成的重排重绘卡顿与异步悬挂。

### 3. Pinterest 视觉找图（以图搜图）重构
- **精准局部寻源**：支持在画稿上自由框选灵感细节进行局部以图搜图。
- **双模智能容错**：原图直接解析 + 缩略图自愈降级，自动白底平滑融合，彻底告别透明背景裁切图黑边。

### 4. 双核查重矩阵（精确查重 + AI 语义查重）
- **毫秒精确查重**：大小分桶预筛 + 快速分块 Hash + 逐字节防碰撞确证，秒级发现重复冗余画稿并统计可释放空间。
- **AI 语义查重**：本地 8×8 dHash / 宽高比初筛 + 标准 OpenAI 兼容多模态视觉接口精筛，可自由配置私有 API 地址、Key 与视觉模型，精准识别裁切、缩放、重压及微调版本。

### 5. 专为画师打磨的细节交互
- **MP4 视频动态缩略图**：自动截取视频代表帧，动态素材一览无余，告别黑框。
- **无框沉浸式五星评分**：去除非必要黑底，与上方动态色板协同呼应。
- **极简灯箱展示**：双击进入图片后，设有鼠标靠近才会浮现的隐蔽按钮机制，正常浏览观察缩放图片时享有极致的原生体验。
- **外部拖入“防手滑”安全锁**：外部素材拖入与内部整理完全对齐整行归类逻辑，彻底关闭上下间隙白线指示，杜绝手滑误入未分类。
- **绝对数据安全底线**：所有素材与文件夹删除一律移至 **Windows 原生回收站**，随时可撤回还原，数据万无一失。
