# PicNest 图巢 · Logo 底稿

## 设计方向

- **气质**：暖纸、墨线、一点金。和软件里的「暖砂底 / 金色强调 / 编辑排印感」同一套语言，而不是通用科技蓝。
- **语义**：图巢 = 图片的巢。三个概念都围绕「照片 / 收藏 / 巢」展开。
- **约束**：16px 仍要能认；最多两色 + 一个金色点；不要细羽毛、不要小字；圆头线、统一线宽。
- 颜色：墨 `#2C2A26`，暖纸 `#F4EFE7`，金 `#B4884B`；深底版本用纸白线 + 金点。

## 三个概念

| 概念 | 文件 | 说明 | 适合 |
|---|---|---|---|
| **A 巢 · 照片卡（推荐）** | `concepts/nest.svg` | 一张带太阳/山的照片卡，被 U 形巢弧托住，金色小蛋做落点。语义最完整：照片 + 收藏 + 巢。 | 主图标、关于页、启动图 |
| **B 巢鸮（猫头鹰）** | `concepts/owl.svg` | 耳朵 + 双眼 + 喙 + 巢弧；猫头鹰＝夜巡/注视细节/收藏，和「巢」同音。 | 吉祥物、空状态、插件/周边 |
| **C N 字母标** | `concepts/monogram.svg` | 圆角画框 + 贯穿的 N（Nest）+ 右上金点；结构最简，缩小最稳。 | 任务栏 16–32px、favicon、极简场景 |

浅底/深底对照见 `preview-sizes.png`，三个概念并排见 `preview-concepts.png`。深底版本在 `concepts/*-dark.svg`（墨线换纸白，金色不动）。

## PSD 模板（给你在 PS 里画）

`PicNest-logo-template.psd` — 2048 × 2048，透明画布，图层从下到上：

1. `背景-暖纸（可隐藏）` — 铺满的 `#F4EFE7`，不需要透明底时留着。
2. `参考-安全区 80%` — 205px 内缩的圆角虚线框 + 内层 20% 参考。
3. `参考-圆角 22.5%` — 应用图标圆角参考（2048 下半径 460）。
4. `参考-网格 64` — 每 128px 一条（对应 1024 画布的 64px）。
5. `参考-中心` — 十字 + 中心圆。
6. `底稿 A 巢·照片卡` — 默认显示，可直接描/改。
7. `底稿 B 巢鸮（可隐藏）`
8. `底稿 C N字母（可隐藏）`

用法：打开 PSD → 只点亮你要画的底稿（或全部关掉自己画）→ 参考线保持在最上层 → 画完后隐藏参考线 → 导出 1024×1024 PNG。画布是 2 倍尺寸，线条/圆角都可以按 2 的倍数缩放。

## 导出规格

- 主图标：1024×1024 PNG（透明）；再导出 512 / 256 / 128 / 64 / 48 / 32 / 16。
- Windows 任务栏/开始菜单需要 `.ico`（16/24/32/48/64/128/256 多尺寸），可由 1024 PNG 生成。
- 深色任务栏/暗色主题：用 `-dark.svg` 的纸白线版本，或者给图标加暖纸圆角底（这时墨线版也能用）。
- 圆角/留白：应用图标按 22.5% 圆角、80% 安全区；不要让图形贴边。

## 设计检查清单

- [ ] 缩到 16px 还能看出「照片/巢/N」吗？
- [ ] 深底、浅底都成立（墨线 vs 纸白线）？
- [ ] 金色点仍是唯一高饱和色，面积不超过整体 1/20？
- [ ] 没有文字、没有依赖细线的小结构？
- [ ] 和软件里的暖纸面板、金色选中框放在一起不打架？

## 终稿方向：黑底 N 标（`final/`）

最终以你最新保存的 `PicNest-logo-template.psd` 可见层合成结果为准：**纯白 N + 更大的浅金色蛋点 + 纯黑圆角 tile**（N 底部保留了你在 PSD 里画的分隔缺口），底色为最黑的 `#000000`。PSD 母版保持原样。仓库保存了这份 PSD 原件：

- `final/PicNest-logo.psd`（最终母版，2048 × 2048，参考层均已隐藏）
- `final/picnest-icon-1212.png`（从 PSD 裁出的原生 tile，后续尺寸的母本）
- `final/picnest-icon-2048.png` / 1024 / 512 / 256 / 128 / 96 / 64 / 48 / 40 / 32 / 24 / 20 / 16
- `final/picnest.ico`（16/20/24/32/40/48/64/96/128/256 共 10 档 PNG 帧，Windows 用）
- `final/preview-icon.png`（浅底/深底 + 缩小可读性检查）

**分级 N 比例**：16–48px 小尺寸把 N 放大到 tile 的 **88%**，64px 及以上用 **76%**——小图标不会因为黑边太厚而糊成一团，大图标仍保留宽黑边。ICO 每一帧都按目标尺寸单独从 1212 母本缩放（而不是从 256px 帧再缩），任务栏/开始菜单取帧更锐。

终稿已接入 PicNest 的窗口/任务栏图标（`app/_internal_data/icon.png` 与 `icon.ico`，原件备份为 `icon-old.*`），并用 resedit 把同一份 ICO 写入 `PicNest.exe` 的 PE 图标资源；VersionInfo 保持 FileDescription `PicNest` / ProductName `PicNest 图巢` / OriginalFilename `PicNest.exe`（exe 原件备份为 `app/PicNest.exe.picrand.bak`）。窗口标题、托盘、任务栏 AppDetails、package.json 应用名均已改为 PicNest。

> Windows 任务栏会缓存按钮图标：换 exe 内嵌图标后若任务栏仍是旧图，结束 explorer、删除 `%LOCALAPPDATA%\IconCache.db` 与 `%LOCALAPPDATA%\Microsoft\Windows\Explorer\iconcache*.db`，再启动 explorer 并重启 PicNest。实测清理后任务栏按钮名为 `PicNest - 1 个运行窗口`，图标为黑底白 N + 金点。

几何版 N（无笔刷细节）保留为备选矢量：`concepts/monogram-geometric-draft.svg`，只在需要重新矢量化时参考。侧栏品牌字标仍保持「图巢 / PicNest」文字，不混入图标。
